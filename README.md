# 🏙️ Идеальный мэр
Симулятор управления городом с элементами детектива и загадки. 
Вы набираете 100% голосов на выборах и становитесь мэром города Блик. Город встречает вас тишиной и пустыми улицами. У вас есть 12 месяцев, чтобы построить процветающий мегаполис, прислушиваясь к жителям, и понять, что же на самом деле происходит в этом городе.

## 🎮 Геймплей
*   **Строительство:** Возводите здания на карте. Расположение имеет значение: заводы рядом с домами снижают счастье жителей, а промышленные кластеры (заводы рядом) дают бонус к доходу, но сильнее бьют по экологии.
*   **Экономика:** В конце каждого сезона собираются налоги, начисляется доход с производств и тратятся ресурсы на содержание соцсферы. Следите за балансом!
*   **Инфраструктура:** Жилые и промышленные здания можно строить только рядом с дорогами.
*   **Достижения:** Получайте ачивки за ваши действия.
*   **Автосохранение:** Весь прогресс (ресурсы, постройки и достижения) сохраняется в базе данных SQLite.

## 🚀 Технологии
*   **Язык:** Python 3.12
*   **Интерфейс:** PyQt6
*   **База данных:** SQLite3

## 📦 Установка и запуск
1. Клонируйте репозиторий:
   git clone https://github.com/TheBlik/IdealMayor.git
   cd IdealMayor
2. Установите зависимости:
   pip install -r requirements.txt
3. Запустите игру:
   python main.py
