# Идеальный мэр

Градостроительный симулятор на Python с использованием PyQt6.

## Об игре
Вы мэр города Аллотерра. За 12 сезонов вам нужно превратить пустошь в мегаполис. Но главная задача — раскрыть тайну: почему абсолютно все жители проголосовали за вас?
